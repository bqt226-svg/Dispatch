# Dispatch

Стартовая версия системы диспетчеризации смены. Откройте `index.html` в браузере. Установка зависимостей не требуется.

## Работа со сменой

1. Выберите дату и тип смены. Дневная и ночная смены имеют отдельные журналы. Для ночной смены используйте дату её начала.
2. Добавьте заявку, укажите приоритет и ответственного.
3. Обновляйте статус заявки по ходу смены. Сводка пересчитывается автоматически.
4. Скачайте CSV выбранной смены для передачи или анализа.

Данные сохраняются в браузере на текущем устройстве. Новый проект использует отдельное хранилище и стартует с пустого журнала. Для первого знакомства можно загрузить демонстрационные заявки. CSV содержит все заявки выбранной смены независимо от фильтров. Время выполнения считается от регистрации до последнего перевода в статус «Закрыта».

Для совместной работы потребуются серверное хранилище, учётные записи и история изменений.
